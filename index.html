What is Surogate?

Surogate is a hosted platform for building, deploying, and improving autonomous AI agents. You don't manage Kubernetes, model serving, policy enforcement, or the LLM loop yourself — the platform handles the runtime so you focus on what the agent does.

The platform is built on three open-source components:

  • surogates — the agent runtime (harness, sessions, sandbox, governance, MCP integration)
  • surogate-ops — the operator platform (the UI, billing, hub, training pipeline)
  • surogate-hub — the lakeFS-backed artifact versioning store
