---
title: Data
description: The data models, with their fields, links and how many records each holds.
---

**Data** lists the portal's [data models](/portal/sites/data-models/) for administrators: each model's name and id, about how many records it holds, and its fields, each with its type, the model it links to, and a `*` when it is required. Models are written in the portal's files.

**Query** opens the [data console](/portal/console/data-console/), to ask the data models questions in SQL.

Above the list, **Relations** draws how the models link to each other, and lists each link in words: the model and field, the model it points at, and whether it holds one record or many.
