---
title: Guides
description: The user guides the portal shows, where each applies and how it starts.
---

**Guides** lists the portal's [user guides](/portal/sites/guides/) for administrators: each guide's name, how it starts (when asked for, or on the first visit), its number of steps, and the sites and pages it applies to. To see one, open one of its pages with `?guide=<id>` at the end of its address. The console does not write guides yet. For now, this is set in the site's configuration: see [Developer: User guides](/portal/developer/guides/).
