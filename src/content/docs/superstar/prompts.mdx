Every prompt from the [playbooks](/superstar/#i-want-to), as people type them at Halcyon Data. Copy one and change the names.

A prompt that starts with an @name goes in a block on the page you want the work on: type it on an empty line. The others go in **Ask** (**Ctrl J**), and Superstar picks who does it. Name the table or page to use, and say what to leave out.

## Sales

[Open the playbook](/superstar/playbooks/sales-desk/)

