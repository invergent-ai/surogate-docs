# Projects & Teams

Admins manage who belongs to the workspace and what each person can do from one page: **Settings → Projects & Teams**.

This tab is hidden from the Settings sidebar for non-admin accounts. You'll see it when you have the admin permission set.

## The page

Lists your projects with these actions:

- **+ New Project** (top-right) — opens the project creation dialog.
- A row menu (**⋯**) per project — rename, archive, delete.
- **+ Invite** per row — add a member by username or email.
- **Edit** per row — change name, color, archive status.

## Create a project

Fields:

- **Name** — display label.
- **Color** — chip used to distinguish projects in the UI.

Submit. You're set as the owner.

## Invite a member

On a project row, click **+ Invite**. Enter a username or email and pick a role:

- **Owner** — full control of the project plus member management.
- **Editor** — read plus create and update on the project's resources.
- **Viewer** — read-only.

Submit.

## Archive a project

A project can be archived from the row menu. Archived projects drop out of default lists; their data is retained. Unarchive from the same menu.
