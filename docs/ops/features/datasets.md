# Datasets

## What it does

A **Dataset** is a collection of training, eval, or fine-tuning examples. Datasets are produced by:

- **Import** from a file or a Hub repo.
- **Capture** from agent interactions (turn sessions into training data).
- **Synthetic** runs (a pipeline kind under Compute → Workload Queue produces synthetic data).
- **New Dataset** built from scratch in the UI.

## When to use it

- Building the dataset for an upcoming Training run.
- Curating eval fixtures.
- Seeding an Expert model on captured interactions.

## Status / kinds

A Dataset has a **kind** that constrains its schema. Kinds the codebase references:

- `sft` — supervised fine-tuning examples.
- `eval` — eval fixtures.
- `synthetic` — generated by a synthetic pipeline.
- `environment` — bound to an RL/agent training environment.

## Edge cases and gotchas

- A Dataset bound to an **Environment** ([Hub](./hub) repo of type `Environment`) inherits its observation/action schema — schema validation runs on every add.
- Imports from the Hub respect repo branches (a Dataset can target `repo@branch`).
