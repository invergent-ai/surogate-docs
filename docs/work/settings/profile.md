# Profile

| Field | Notes |
|---|---|
| **Name** | Display name. Editable. |
| **Email** | Login. Changing requires re-verification. |
| **Role** | Free-form. Shows next to your avatar in the platform header. |
| **Bio** | Short freeform used in some collaborative views. |
| **Avatar** | Upload, or pick from 12 presets (`marble-cosmos`, `marble-aurora`, `beam-helix`, `beam-orbit`, `pixel-byte`, `pixel-glitch`, `sunset-dunes`, `sunset-coast`, `ring-haven`, `ring-pulse`, `bauhaus-prism`, `bauhaus-grid`). |
| **Change Password** | Sends a reset link by email. After setting a new password you're signed out and need to sign in again. |

The slug (login local-part) is locked behind a **Rename** button — separate flow from the inline editable fields.
